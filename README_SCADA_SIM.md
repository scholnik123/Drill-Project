# SCADA Intelligent Simulation v2.0

This folder is a Unity project skeleton with a runtime bootstrap.

Open the folder in Unity 2022 LTS or newer, press Play in any scene, and the simulator creates:

- procedural onshore/offshore drilling environments;
- procedural directional wellbore mesh from survey stations;
- drilling physics model with torque, drag, ROP, pressure, vibration, and risks;
- crew management model with fatigue, morale, experience, reaction delay, and errors;
- Edge AI recommendation module;
- industrial SCADA-style runtime dashboard.

Runtime controls:

- right mouse drag: orbit camera;
- mouse wheel: zoom;
- bottom SCADA buttons: change RPM, WOB, flow, rest crew, switch onshore/offshore.
